株式チェック：中継サーバーを設置する

GitHubの株式アプリとJ-Quantsの間に、自分専用の通信窓口を作ります。キングアプリとは別の株式投資用リポジトリで作業します。

プログラムの試験は完了していますが、公開サーバーはまだ設置されていません。J-Quantsの実データ取得は、設置後に本人のAPIキーで確認します。

① 株式用GitHubへ4ファイルをアップロード

yakamikoujinen-stack/akihiro-future の一番上の階層へ、次の4つをアップロードします。

  • stock-analysis-test.html：v1.3のアプリ。同名ファイルを上書き。
  • stock-jquants-worker.js：中継プログラム。
  • wrangler.jsonc：中継プログラムの設置設定。
  • stock-relay-setup.html：この手順書。

APIキーはどのファイルにも書き込みません。GitHubへAPIキーをアップロードしないでください。

② Cloudflareに登録

Cloudflareの登録画面を開く

アカウント作成とメール確認を行います。中継用にはWorkersの無料枠を使います。J-Quantsの料金とは別のサービスです。独自ドメインを購入する必要はありません。

Cloudflareにログインし「Workers & Pages」を開きます。画面が異なる場合はその画像を相棒に送ってください。メール・パスワード・APIキーは写さないでください。

③ GitHubから中継プログラムを設置

  1. 「Create application（アプリケーションを作成）」を選びます。
  2. 既存GitHubリポジトリの接続を選び、akihiro-future を選択します。接続許可を選べる場合はこのリポジトリだけを許可します。
  3. Worker名は fujiwara-stock-relay。ルートディレクトリはリポジトリのルート（/）。
  4. ビルドコマンドを求められたら空欄。デプロイコマンドは npx wrangler deploy。wrangler.jsonc で実行するファイルが指定されています。
  5. 「Deploy」を押します。エラーの場合はAPIキーを入れず、エラー画面を相棒に送ってください。
  6. 公開後に表示される https://fujiwara-stock-relay.自分の名前.workers.dev のURLをコピーします。URLを開くと「中継サーバーが稼働しています」と表示します。

コード編集画面から作る方法が表示された場合は、下のプログラムを貼り付ける方法も使えます。

④ 株式アプリで接続確認

  1. 株式アプリを開き、上部が「v1.3」になっているか確認します。旧版なら、いつものURLをブラウザで再読み込みします。
  2. 「ネット取得の接続設定」を開き、「自分の中継サーバーURL」に公開したURLを貼り付けます。末尾に /api は付けません。
  3. 「中継サーバーの接続確認」を押します。自分のCloudflareに設置したURLであることを確認します。
  4. 契約済みのJ-Quantsプランを選び、J-QuantsのAPIキーを入力します。
  5. 一番上の検索欄に 9432 を入力し「データを読み込む」を押します。「NTTで試す」は固定データ表示なので、通信確認には使いません。
  6. 「J-Quantsから…期の通期実績を取得しました」と表示されるか確認し、数字・出典・株価基準日を確認して「気になる銘柄に保存」を押します。

「中継サーバーへの接続を確認しました」だけでは、J-Quantsの認証が成功したことにはなりません。銘柄読込まで確認します。APIキーはアプリを閉じると消えます。中継URLとプランはこの端末に保存します。

プログラムをコピーする場合

Cloudflareにコード編集画面がある場合、既存コード全体をこのコードに置き換えて公開します。GitHub接続で設置できた場合は不要です。

GitHubへ置く設定ファイルの内容
{
  "name": "fujiwara-stock-relay",
  "main": "stock-jquants-worker.js",
  "compatibility_date": "2026-10-03",
  "workers_dev": true,
  "observability": { "enabled": false }
}

エラーが出た場合

  • 中継接続確認で失敗：公開URL・公開状態・設置したプログラムを確認。
  • J-Quantsが取得を拒否：本人のAPIキーと、実際に契約済みのプランを確認。
  • 回数上限：1分ほど待って再試行。
  • 数値の空欄：未開示・取得期間不足・分割確認が必要な期は空欄です。値を0に置き換えません。

サーバー側にAPIキーを保存する機能はありません。通信先はJ-Quantsの公式APIに固定しています。このプログラムはキー・本文をログに書かず、設定ファイルでも実行ログを無効にしています。

個人の銘柄分析に使用してください。第三者へ取得データを公開する機能はありません。
